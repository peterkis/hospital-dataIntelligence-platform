# 04 — 价表草稿、完整快照与计划发布

**What to build:** 让价格数据管家组装、修改和删除完整价表草稿，查看相对上一发布的变化，并按明确业务生效时间发布不可变完整快照。

**Blocked by:** 03 — 收费项目版本、双时态与差异查询.

**Status:** claimed

- [ ] 价表稳定身份、草稿和发布版本分离，草稿可以增删价格条目但不会被解析或消费。
- [ ] 每个价格条目冻结收费项目稳定身份和明确发布版本、金额、币种、计价单位、范围、场景模式和业务有效期。
- [ ] 提交前可以查看相对上一价表发布版本的新增、移除、调价和适用期变化。
- [ ] 发布形成完整不可变价表快照，后续调整创建新发布版本而不是修改历史。
- [ ] 计划发布在业务生效时间之前可完成审批，但价格解析只按服务发生时点选择已生效版本。
- [ ] REST、管理界面、双时态查询、真实数据库约束和发布回归测试共同通过。
