# 10 — 收费项目CSV与REST批量导入

**What to build:** 让数据管家通过冻结UTF-8 CSV或等价REST JSON批量导入收费项目草稿，获得确定性的批次内判重、行级部分成功和错误证据。

**Blocked by:** 02 — 收费项目草稿CRUD闭环; 06 — 治理对象级与院区范围授权.

**Status:** ready-for-agent

- [ ] 一个批次冻结治理对象、对象类型、来源种类、Schema版本、原始内容摘要、提交主体和不可变行身份。
- [ ] CSV使用固定编码、表头和列顺序；JSON使用相同逻辑行Schema，二者产生相同规范化内容和领域结果。
- [ ] 全批次预扫描业务键，同键多行全部标记冲突，禁止以行顺序决定首条成功。
- [ ] 不冲突的有效行各自成功形成草稿；单行失败不回滚其他成功行，也不自动提交审批或发布。
- [ ] 每行保存稳定结果、错误码、规则版本、引用证据和尝试序号，批次汇总与行结果一致。
- [ ] UI支持上传、查看进度与行级结果；REST、真实数据库和浏览器场景覆盖混合成功与失败。
