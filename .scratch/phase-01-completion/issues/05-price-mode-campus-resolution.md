# 05 — 价格模式、院区回退和失败关闭

**What to build:** 完整实现并展示通用/专用场景互斥、院区到全院固定两级解析、服务发生时点计价，以及同层冲突和无价格的失败关闭结果。

**Blocked by:** 04 — 价表草稿、完整快照与计划发布.

**Status:** claimed

- [ ] 同一可定价对象、价表、组织范围和业务时段内，通用模式与专用模式不能同时发布。
- [ ] 专用模式只接受门诊、住院、急诊和体检四类实际场景；通用只是覆盖四类的通配模式。
- [ ] 解析先查找明确批准的院区差异价，不存在时才回退全院默认价，不使用数字优先级。
- [ ] 任一层存在多个有效候选时返回确定性冲突错误，无价格时返回明确无价格结果。
- [ ] 解析证据冻结业务/记录时点、候选、按序检查步骤、命中或回退路径、结果摘要和解释码。
- [ ] 管理界面可配置正反场景并查看解析证据；所有分支通过生成客户端和真实数据库测试。
