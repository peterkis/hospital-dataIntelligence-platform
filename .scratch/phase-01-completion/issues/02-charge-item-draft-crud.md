# 02 — 收费项目草稿CRUD闭环

**What to build:** 让数据管家通过REST和管理界面对收费项目草稿执行新增、查询、修改和删除，同时证明已发布收费项目版本不能被修改或删除。

**Blocked by:** 01 — 真实浏览器验证现有纵向切片.

**Status:** ready-for-agent

- [ ] 收费项目稳定身份与草稿版本分离，创建草稿不会形成发布、快照、Outbox或消费者事件。
- [ ] 数据管家可以查询、编辑并删除未提交草稿，所有成功动作记录对象、主体、请求和内容摘要审计。
- [ ] 草稿内容校验与现有发布路径使用同一领域规则，不在路由或浏览器复制规则。
- [ ] 已提交或已发布版本的更新和物理删除请求失败关闭并留下拒绝证据。
- [ ] 数据库约束和业务账号权限共同证明已发布记录不可覆盖或删除。
- [ ] TypeBox、冻结OpenAPI、生成客户端、REST测试和真实浏览器CRUD场景同步完成。
