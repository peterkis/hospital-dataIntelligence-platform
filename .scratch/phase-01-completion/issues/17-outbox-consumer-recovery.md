# 17 — Outbox与消费者故障恢复

**What to build:** 让Outbox派发和两个隔离仿真消费者在唤醒丢失、租约过期、网络失败、进程崩溃、重复投递和版本缺口下恢复，并保留独立顺序与证据。

**Blocked by:** 09 — 纯投影Schema升级限定例外; 16 — 发布事务逐写点原子故障矩阵.

**Status:** claimed

- [ ] 提交后唤醒丢失时数据库轮询发现待投递事件并恢复，不依赖进程内信号正确性。
- [ ] 租约在短事务中通过并发安全认领，网络期间不持有数据库锁，过期租约可被回收。
- [ ] 消费者成功后、投递结果落库前崩溃会产生可幂等重复投递，不会重复应用领域版本。
- [ ] 两个消费者拥有独立状态、尝试序号、重试、顺序阻断和影响事项，一个失败不阻断另一个。
- [ ] 已有检查点后只允许严格下一聚合版本，缺口阻断应用、回执和检查点推进。
- [ ] Toxiproxy及受控进程故障覆盖网络、重试耗尽和恢复，结果进入公共消费闭环和正式证据。
