# 06 — 治理对象级与院区范围授权

**What to build:** 让不同人员和服务身份对收费项目、价表及院区范围得到可验证的允许或拒绝结果，确保权限只来自平台本地对象级授权。

**Blocked by:** 02 — 收费项目草稿CRUD闭环; 04 — 价表草稿、完整快照与计划发布.

**Status:** claimed

- [ ] 每次受保护操作按本地主体、治理对象、操作、院区范围和有效期求值，不按名称或Keycloak业务角色推断。
- [ ] 同一人员可以组合获得多项权限，但权限不会扩展到未授权治理对象或院区。
- [ ] 显式拒绝、过期授权、错误院区、错误对象和未绑定外部身份全部失败关闭。
- [ ] 院区数据管家可以维护院区草稿但不能批准或覆盖全院条目。
- [ ] 服务身份只能执行其消费相关能力，不能提交、审批、发布或维护领域数据。
- [ ] REST与浏览器使用真实外部身份验证允许/拒绝矩阵，并记录授权判定审计。
