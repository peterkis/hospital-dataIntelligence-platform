# 07 — 普通内容变更的版本化审批

**What to build:** 让收费项目和普通价表内容变更通过冻结模板版本的提交、复核、Owner终审和自动发布流程，阻止普通内容自批、跳级和内容漂移。

**Blocked by:** 03 — 收费项目版本、双时态与差异查询; 04 — 价表草稿、完整快照与计划发布; 06 — 治理对象级与院区范围授权.

**Status:** claimed

- [ ] 变更请求冻结变更分类、风险结果、审批模板版本、必需阶段、职责分离策略、内容摘要和强制证据。
- [ ] 提交、复核和终审分别验证对象级权限及阶段顺序；未知、跳级、倒序和终态后动作失败。
- [ ] 普通领域内容变更的提交人与最终审批人不能是同一本地人员主体，即使使用不同外部账号也不能绕过。
- [ ] 审批期间草稿内容变化导致摘要不一致并阻断后续动作。
- [ ] 模板新版本不迁移进行中的变更请求，不存在超时自动批准、任意脚本或外部流程旁路。
- [ ] 最终批准与领域发布、快照、审计和Outbox保持原子，管理界面展示每个阶段和证据。
