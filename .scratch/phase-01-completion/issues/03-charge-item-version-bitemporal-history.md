# 03 — 收费项目版本、双时态与差异查询

**What to build:** 让治理用户在同一收费项目稳定身份下建立新版本候选，并查询完整版本历史、指定业务时点、指定记录时点、追溯更正前后结果和版本差异。

**Blocked by:** 02 — 收费项目草稿CRUD闭环.

**Status:** ready-for-agent

- [ ] 已有业务键在交互维护中形成新的草稿版本候选，不覆盖既有发布版本或复用其他稳定身份。
- [ ] 发布版本使用业务有效区间和记录有效区间表达双时态，当前与历史查询结果可复现。
- [ ] 追溯更正只关闭旧记录时间并追加更正版本，历史记录时点仍返回更正前内容。
- [ ] 版本历史按显式版本序号排序，日期时间不承担权威顺序。
- [ ] 两个版本的字段差异、业务时间差异及生命周期差异可通过公共API和界面查看。
- [ ] PostgreSQL范围约束、真实数据库测试、生成客户端和Playwright历史查询场景全部通过。
