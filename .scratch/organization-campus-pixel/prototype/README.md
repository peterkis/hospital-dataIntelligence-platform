# 组织与院区交互原型

本原型使用 shadcn/ui、React Flow 和 React，按用户提供的 1440 × 1000 截图复刻。当前预览：[组织与院区](http://127.0.0.1:4322/)。

2026-10-14 按用户后续意见，关系图借鉴 [ReUI Flow](https://reui.io/blocks/application/flow)：节点采用图标与名称／编码头部、分隔线和类型／状态底栏；连接线采用细灰虚线折线与小连接点；“运行”使用青绿色标签，“筹建／草稿”使用琥珀色，“示例持证登记”保持中性，运营关系标签使用淡蓝色。关系标签支持点击和键盘打开详情。节点位置、尺寸、关系期间及页面外壳保持既有布局。

使用“部门与服务单元”，下分门诊单元、住院单元、急诊单元、医技单元。附件中的机构、院区、编码、状态、2026-10-11 演示日期，以及 2024-01-01、2025-06-01 关系起点均保留。

支持关系图与表格、分类切换、日期和院区筛选、对象与关系详情、当前页面草稿、新增对象、搜索、缩放、平移、布局调整、场景重置和虚构角色切换。较窄屏幕收起侧栏文字，图形提供总览与缩放，表格可横向滚动。

全部数据保存在页面内存，刷新后重置。本目录使用独立依赖和构建配置，开发服务绑定 127.0.0.1:4322，拒绝 `/api` 请求。此原型没有业务接口、数据库、真实审批、权限或证照核验能力。

## 本地维护

在本目录执行 `npm ci` 安装锁定依赖，`npm run dev` 启动预览，`npm run build` 执行类型检查并构建。`npm run typecheck` 可单独检查类型。预览已由本次任务启动。

源码入口为 `src/App.tsx`；样例对象和期间位于 `src/data.ts`；图形交互位于 `src/OrganizationGraph.tsx`；视觉样式位于 `src/styles.css`。shadcn 组件位于 `src/components/ui/`。

当前交付检查见 [design-qa.md](design-qa.md)，上一版检查保存在 [design-qa-before-reui.md](design-qa-before-reui.md)。2026-10-14 用户授权将本独立原型提交并推送至 Git 远程。没有发布站点，也没有改动现有维护工作台、接口或数据库。截图、原始测量和本机保留检查存放在忽略的 `evidence/` 目录，依赖与构建产物也不纳入 Git。Sites 适配文件按初始化模板保留；Sites 专用测试尚未运行，站点发布仍属于后续授权范围。
