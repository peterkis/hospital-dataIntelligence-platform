# 验收检查清单

## 1. 文档和资产

- [ ] 总体/详细设计、网络、安全、数据库、接口、数据字典、Topic、部署、监控、备份、灾备和操作手册齐全；
- [ ] 源码、构建脚本、SBOM、镜像、Helm、配置、规则、映射、Schema和测试数据由医院托管；
- [ ] 所有生产资产有Owner/Steward、分类分级、用途和生命周期；
- [ ] 新增系统接口通过OpenAPI/AsyncAPI/FHIR/批量契约测试。

## 2. 功能

- [ ] 患者金记录、多标识、xref、候选、人工仲裁、合并与回滚；
- [ ] 组织/科室/病区/床位双时态、撤并、改名和历史查询；
- [ ] 人员主体与任职/角色分离，离职/调岗及时传播；
- [ ] 药品、诊疗项目、耗材、设备、供应商生命周期和多码映射；
- [ ] CodeSystem/ValueSet/ConceptMap版本发布、翻译、checksum和回退；
- [ ] 质量门禁、工单、根因、修复、复检、关闭和考核；
- [ ] 元数据目录、字段定义、Owner、血缘、影响分析和申请入口。

## 3. 性能与可靠性

- [ ] API 3000 QPS持续2小时，P95≤500ms、5xx<0.1%；
- [ ] 患者候选匹配P95≤800ms，超时有安全降级；
- [ ] CDC 3万条/秒短时峰值及历史回灌并行不影响源库批准阈值；
- [ ] Kafka断连、恢复、重复、乱序、Schema演进、DLQ和回放通过；
- [ ] PostgreSQL、Kafka、K8s、OpenSearch、Ceph单节点/盘故障测试通过；
- [ ] 峰值1.5倍或医院批准的扩展压测通过，容量无红线。

## 4. 安全与合规

- [ ] PIPIA/数据安全风险评估、分类分级、最小必要和数据出域识别完成；
- [ ] OAuth2/OIDC、MFA、mTLS、RBAC+ABAC、行列权限、脱敏和令牌化有效；
- [ ] 越权、IDOR、注入、密钥泄露、日志泄敏、供应链和容器安全测试通过；
- [ ] 查询、导出、合并、回滚、审批、策略/规则变更100%审计；
- [ ] 科研沙箱、导出水印、期限、结果审查和到期回收可验证。

## 5. 备份和灾备

- [ ] PostgreSQL PITR、对象存储、OpenSearch、配置、证书和密钥恢复通过；
- [ ] 患者误合并、标准误发布和事件重复副作用可回滚/补偿；
- [ ] 双中心切换：关键MDM/API RTO≤30分钟、RPO≤5分钟；
- [ ] 无双主、无数据丢失、审计连续；业务Owner完成验证并签字。

## 6. 组织和运营

- [ ] 域Owner/Steward任命并完成考核、培训和替补机制；
- [ ] 监控SLO、告警分级、值班、工单和月报运行至少一个完整周期；
- [ ] 旧维护入口退役计划和下游订阅责任人明确；
- [ ] 重大故障、患者安全和数据泄露应急预案完成演练；
- [ ] 合同退出、数据导出、知识转移和第三方替换验证通过。
