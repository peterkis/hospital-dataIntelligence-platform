# 任用关系独立建模并按规则受控并存

任用关系不作为人员主体上的类型或在职状态字段，而作为具有独立关系ID、正式依据、业务有效期、双时态和不可变版本的治理对象。一级类别为劳动或人事任用、派遣或服务任用、外部专业任用、培训或学习任用，具体二级类型由版本化字典表达。连续续聘、期限延长或属性修订沿用原关系ID；关系结束后再次任用，或者法律及管理基础改变时新建关系ID，但人员稳定ID不变。同一人员可以并存多项任用关系，其时间重叠由版本化规则矩阵判定为允许、禁止或必须复核。草稿、审批、发布和失效等治理状态与计划生效、生效中、暂停和结束等业务状态分离，均不得写回为人员主体的当前状态。
