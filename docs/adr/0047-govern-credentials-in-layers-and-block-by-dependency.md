# 专业资质分层治理并按依赖关系阻断

专业资质由可版本化的资质定义、个人资质实例、可多值的资质范围、只追加核验记录和任职资质要求组成，资格、执业注册、签发、范围、有效期和核验不得压缩为单一人员字段。医师资质由医务管理Owner审核，护士资质由护理管理Owner审核，进修、规培和实习证明由教学管理Owner审核；人力资源权威来源可以提供初值和材料，但不代替专业审批。缺失、未核验、已到期、已撤销或范围不匹配的资质，错误级阻断依赖它的新任职、续任和未来临床消费；临近到期只预警。已发布任职遇到资质到期或撤销时不自动结束或改写，而从相应业务时点阻断其临床可用性投影并生成影响事项，历史结果和无关行政用途保持可用。POC覆盖医师资格、医师执业注册和护士执业注册，不建设完整证照目录或具体手术及操作授权。
