# 机构稳定主体与独立证照权威

P1-01 根据用户确认的计划，在同一医院治理边界内建立 organization-master；它不扩大为多医院或多租户。机构名称不唯一，DB 签发 stable ID，证照和登记代码仅作为分命名空间的归属声明。冲突阻断第二主体，候选仍保留；不自动合并、转移或暂停第一主体。

主体版本、证照版本和核验事实分别不可变，内容修订不更换主体身份。证照号码保留于受保护输入；冲突索引为带独立 domain 的 HMAC，不保存号码普通 SHA。公开事实不含号码、材料原文和源定位。核验绑定完整期间、准确主体及证照版本和真实来源材料；未来证照不能覆盖过去。资格查询区分记录时点已知事实与后续撤销，院区运营许可始终由 P1-04 承担。

源 ORG01 的 license_valid_to 仍是 date。用户明确要求本票手工接口另支持本地日期时间：日期按当天零点排他结束，时分秒按输入时刻排他结束，原值留于加密输入。无固定期限须经核验；未知期限不能发布持证状态。该采纳不修改冻结源 schema，不静默为文件导入升级格式。

本票复用 P0-08 的冻结候选、读取回执、审批、outcome、审计与事务作用域。手工 CORE 命令使用独立静态契约；已有 import job/revision 仅承担材料输入来源，不表示 ORG01 文件适配器就绪。input/request 绑定阻止同一输入重复产生主体；真实录入 identity 也是候选 maker。来源审批号不能替代本次 maker-checker。

部署仅为 receipt 绑定的本地合成研发环境。沿用现有受信服务账号和 loopback 合成身份选择器，不将请求头身份选择解释为生产认证。生产 composition 必须提供可信 actor resolver。没有建立新认证平台或自动配置真实院办权限。
