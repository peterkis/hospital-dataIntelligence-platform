# 人员域POC限定九组代码系统和六组上下文值域

人员域POC建设任用一级类别、任用二级类型、任职用途、任职方式、岗位类别、任职角色、专业技术职称、专业代码和资质类型九组独立版本化代码系统，并建设任用类别下的任用类型、任职用途下的任职方式、用途及作用域下的任职角色、岗位类别下的职称、资质类型下的专业范围、任职角色可接受的资质类型六组上下文值域。代码系统定义代码身份和含义，值域只选择冻结代码版本中的允许值。平台治理状态、业务生命周期和资质核验结果属于固定状态机；任用重叠、主归属唯一性、角色占用和任职资质要求属于版本化治理规则，均不得作为普通字典任意维护。岗位编制实例、完整职称或专业目录、IAM权限角色不进入POC；人员专业、科室身份和诊疗科目只能通过显式版本化映射关联。
