# POC实行基础治理职责分离

POC区分数据管家、数据Owner、平台管理员、审计员和仿真消费者五类角色。数据管家提交基础数据变更，数据Owner负责审批和发布授权，平台管理员不得参与业务审批，审计员只读核验，仿真消费者使用独立服务账号；任何提交人都不得审批自己的普通领域内容变更。该选择增加了测试账号和授权配置，但可以真实验证治理责任边界。[ADR-0091](0091-govern-projection-schema-upgrades-as-high-risk-contract-changes.md)只对不改变领域内容的纯投影Schema契约升级建立提交人可兼任平台契约终审人的限定例外，不放宽本决策的普通治理变更边界。
