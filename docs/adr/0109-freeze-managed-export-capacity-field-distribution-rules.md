# 冻结受控导出容量画像字段分布规则

容量画像的字段分布必须在消费者交付配置、派生格式和外部字段契约冻结后，按字段身份和稳定记录全序确定生成；不得以运行时随机抽样、名称推断或近似比例形成容量证据。所有比例按每个适用字段分别计算，并通过确定性周期或等价确定算法得到精确数量。`F00`继续只作为24行功能与试验装置控制，不参与下述容量分布或上限推断。

`N10`、`N30`、`N50`和`N100`使用完全相同的普通字段分布规则，只改变最终CSV数据行数：

1. 每个可选输出字段精确70%的记录输出非空值，30%使用消费者交付配置冻结的空值表示；必需字段始终有值。
2. 对每个具备有限合法最大长度、允许合成普通文本且不承担标识、代码或引用语义的变长字符串字段，在其非空值中精确分配70%短值、25%中值和5%长值。
3. 短、中、长值的目标长度分别为该字段冻结合法最大长度的20%、50%和85%，并按画像版本冻结的确定性取整规则收敛到该字段合法最小与最大长度范围。
4. 普通画像使用不含CSV结构字符的安全单字节基线字符集。稳定身份、代码、枚举、引用、摘要及受严格格式或模式约束的字符串由各自合法确定性生成器产生，不进入短中长文本分布，也不能为追求比例而破坏业务键唯一性或引用完整性。

`W50`只隔离字段宽度压力：全部可选输出字段均有值；每个变长字符串字段的目标长度为冻结合法最大长度的90%，并收敛到合法范围。业务键或其他唯一字段所需的确定性唯一后缀必须包含在该90%预算内，不得先填满后再超长追加。数字、金额、日期、日期时间、布尔值及其他非字符串字段使用各自最长的合法冻结序列化表示；字符串继续使用安全单字节基线字符集，使`W50`不同时混入多字节编码压力。

`E50`使用与`N50`完全相同的可选字段非空比例，以及逐字段相同的Unicode码点长度分布，只改变符合条件的文本内容。每个适用文本字段的非空单元格按稳定记录全序精确分为五组，各占20%：

1. 纯中文文本，不含CSV结构字符；
2. 中文与ASCII字母或数字混合，不含CSV结构字符；
3. 中文混合文本并含逗号；
4. 中文混合文本并含双引号；
5. 中文混合文本并同时含逗号、双引号和LF换行。

多字节与转义压力的字段资格必须由画像版本中的显式字段资格清单按精确输出列身份冻结，不得依据列名、显示名或当前内容推断。只有冻结契约明确允许自由文本或展示文本、且其格式、枚举和模式约束允许对应字符的字段可以进入前四组；LF只能进入契约明确允许多行文本的字段。由于每个`E50`适用字段都必须完整形成五组，不允许LF的单行文本字段必须整体排除在五组压力清单之外，只保持`N50`的普通内容规则，不得仅跳过第五组。稳定身份、代码、枚举、引用、摘要、金额、数字、日期、日期时间、布尔值以及不允许相应字符的模式约束字段均排除。任一压力组没有至少一个合法目标字段、字段资格清单与冻结Schema不一致或生成内容不合法时，`E50`画像不得冻结，不能静默跳过或重新分配比例。

字段长度按OpenAPI 3.1所采用的JSON Schema Unicode码点语义判定，最终容量仍只按确定性ZIP精确字节计量；因此`E50`能够在保持逻辑字符长度可比的同时显式测量UTF-8多字节和CSV转义带来的字节增量。画像版本必须同时冻结字段资格清单、非空分布、长度比例、目标长度计算与取整规则、内容类别、字符集合和逐字段确定性分配规则。

本决策不改变七个画像的行数或角色，不扩大72个REST、20个界面场景和Phase 01 ABG-01至ABG-40，也不建立业务模块、数据库表、管理界面、公共API、独立应用、workspace或共享包。受限本机WSL2 Anolis OS 8.9容量环境由[ADR-0110](0110-use-local-wsl2-anolis-8-9-for-capacity-simulation.md)冻结；重复次数、峰值RSS/磁盘余量/时间阈值、结果聚合判定、最终MiB上限和生产部署规格仍须后续逐项确认。
