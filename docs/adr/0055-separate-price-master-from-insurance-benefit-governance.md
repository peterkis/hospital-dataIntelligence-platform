# 价表主数据与医保目录及待遇治理分域

价表主数据只治理院内收费项目语义、价表发布版本和院内价格。医保目录项目作为独立治理对象维护稳定身份、不可变版本、来源证据和生命周期，并通过具有自身类型、有效期、依据、Owner、审批和审计的版本化多对多映射与院内收费项目衔接。支付资格、支付限制、报销比例、自付和封顶等医保待遇规则属于独立待遇治理边界，具体患者资格、结算和报销结果属于业务事实。价格解析先独立确定院内价格，待遇解析随后使用医保目录映射和待遇规则计算支付结果；两次解析分别冻结输入、规则版本和结果，医保身份或待遇结果不得改变或反向覆盖院内价格。长期架构保留两域之间的接口和事件边界；后续ADR-0061和ADR-0065已将医保目录及待遇能力纳入邻接薄切，并量化为8个医保目录项目、10条收费项目医保映射和4条待遇规则。
