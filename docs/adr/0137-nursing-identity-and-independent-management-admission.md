# 护理身份、管理归属与护理业务就绪分离

用户批准 P3-03 计划：care-organization 是护理主数据唯一 Owner。护理单元不是病区、物理护士站、业务单元或个人排班；护理服务级别保留为版本化文本。护理代码全院唯一并终身归属原身份。

CORE 核验真实 Department、Campus 和来源的完整期间。护理部等行政科室可以担任管理组织，不要求管理科室拥有临床服务关系。已登记且未退役的筹建或暂停院区可登记护理组织身份，运营许可、职责、覆盖和护理业务就绪另列 NOT_READY。这一取舍允许提前治理组织身份，代价是 CORE 发布不能被解释为获准开展护理。

归属与属性分别版本化。显式 REBIND 同事务结束旧归属并建立新归属，可改变管理科室和院区而保持护理 ID，不迁移人员、病区覆盖或地点。暂停是持续非扩张事件，保留完整历史，不结束所有归属，也不能被属性修订或未来安排重新激活。恢复与永久退出由 P3-11 另行实现。

原接受依据与当前复核分别保留，未实现覆盖等依赖明确 NOT_EVALUABLE。该 ADR 为 TEST POLICY ONLY 合成开发决定，不代表院方政策采纳、临床运营许可或正式医院验收。
