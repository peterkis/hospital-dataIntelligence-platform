# 区分任用期限历史断言与有效关系权威，并按边界分段评估重叠规则

PV-006-B-04 授权保留历史期限断言的“业务时点适用且记录时点可见”读取语义，
同时将有效任用上下文与生命周期统一为记录时点可见的最新完整期限，再判断业务时点。
这样保留了旧陈述的证据价值，又避免结束或缩短后通过旧开放期限使关系重新有效。

重叠规则继续采用局部区间断言语义：在实际交集内按所有可见规则边界切段，每段取
覆盖该段的最高版本，全部段均 ALLOW 才允许写入；有界失败报告优先级为
FORBID、MISSING、REVIEW_REQUIRED。局部新规则不会抹掉其区间之外的旧规则。
这两类时间语义不泛化到 Person、Identifier 或 Source Mapping，也不改变冻结分类。
