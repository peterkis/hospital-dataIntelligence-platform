# 院区身份、开业计划与自身运营状态分离

用户批准 P1-02 在 organization-master 内管理物理院区，复用公共输入、审批事务及审计。资料、计划和运营断言分别追加，所有动作共享院区整体 expected version；更名不改计划，计划不自动启用。高序号断言只覆盖自己的半开业务区间，真实记录时间由DB产生。业务代码永久保留院区归属，代价是改码后不能释放给另一节点，以消除历史引用歧义。

允许独立批准的未来启用，计划日期不能代替启用审批；实际启用日期不得为未来日期。停用为非扩张动作，可在上游失效时执行，但保留正式来源意图、审批引用、当前权限和 maker-checker。停用覆盖其后已有启用安排，本票不支持恢复或永久退出。

行政区划通过目录中明确 SYNTHETIC_ADOPTED 的准确契约版本绑定。筹建允许地址及区划为空，物理节点启用必须有完整地址、区划成员和覆盖整个期间的采纳依据。真实代码及登记仍待院方确认，自身运行不代替 P1-04 运营许可。既有 NORTH/SOUTH 是合成治理范围，不是新院区ID；调用方收敛由 P1-03 承担。
