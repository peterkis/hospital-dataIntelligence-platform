# 主体院区关系与独立许可范围

按用户批准的 P1-04 计划，主运营方按院区 stable ID 和有效业务分段唯一，不按服务、证照或主体名称拆桶；非主运营关系可共存。关闭终结原关系身份，采用先关闭后独立新建的交接，允许空档，以避免旧审批被复用于新运营方。

许可范围核验与关系版本分别追加；范围绑定准确证照版本、院区 stable ID、服务采纳版本和期间。证照可分段接续但每个服务必须完整覆盖。相关依据变化产生待复核投影，显式审批复核追加依据，普通资料更正不自动重审关系；P1-01 准确主体版本登记门禁仍保留。

本次服务码和 Y/N 为明确合成采纳。地点仅绑定院区身份，迁址不自动使范围失配，此取舍仅适用于合成验证，不可作为真实医疗迁址许可结论。两端 READ 加精确配对授权取代权限笛卡尔积；治理范围 NORTH/SOUTH 不充当院区身份。


持久库已有退役的 ORG03 通用作业 CORE 契约。独立手工 CORE 使用受约束的 manual_org03 身份分类，同数据集/同 profile 每类最多一个，创建时由 Owner 根据 ORG03_MANUAL_CORE_V1 确定，修订不能切换类别。这样保留旧终态与准确引用，避免恢复旧作业契约或把它冒充本票手工服务契约；不新增审批产品或通用契约插件机制。
