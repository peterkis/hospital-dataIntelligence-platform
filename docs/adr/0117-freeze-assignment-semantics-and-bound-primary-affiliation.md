# 冻结每版任职语义并限定主归属声明范围

PV-006-C-02 在当前单医院的全部科室级安置集合中，按人员治理命名空间、人员、任用、用途和作用域约束主归属任职最多一条；具体科室及其治理对象不拆分该约束桶，没有主归属也是合法状态。这是本票新增的保守原型规则，并非完整医院人事政策或 ADR-0046 的全部发布、调动及多作用域能力。

每份已分类任职版本必须与用途、方式的两个独立定义版本同时形成不可变配对。定义采用记录时点可见的最新完整版本，整个任职期限必须落在该版本的适用期内；不回退旧定义补足当前覆盖。未分类历史保留未知，显式采用分类必须追加新的完整任职版本；进入分类后的后续版本不得退回未分类。其他未分类关系使新主归属写入和主归属查询的资料完整性不确定，不能自动推断为兼任或忽略。

主归属声明读取先选记录时点可见的最新完整任职版本，再判断业务期间及该 exact 版本的语义。上游依赖失效不自动释放或删除原声明，依赖复核单独回答其有效性；临床用途标记不构成执业许可。
