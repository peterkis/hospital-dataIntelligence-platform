# 科室病区主要用途与完整共享范围

用户批准P3-04按病区与收治/管理用途分别约束主要关系，源“共享”归入收治，
避免另起类型绕过主要收治唯一性；允许多个非主要收治单元。Ward已批准管理
归属保持权威，管理关系须整段匹配，不反向修改主数据或推导患者收治资格。

共享边界保留源原文，依独立核验的精确规则版本、材料与期间覆盖全部参与
单元。新增共享者超出旧依据时在同批修订受影响关系，代价是增加联合签审，
换取不产生互相矛盾的共享声明。不计算比例、不执行文本、未知须复核。
只开放同院区；完整期间和当前准入同根事务/同R核验，END为永久安全收缩，
失效上游不阻止退出也不自动释放未结束关系的主要占位。身份与旧B/R保留。

本决定仅为TEST POLICY ONLY合成CORE开发；院方政策NOT_ADOPTED，临床
NOT_READY，FULL及护理/空间集成仍分别待验。
