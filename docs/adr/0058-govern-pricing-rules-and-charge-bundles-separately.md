# 复杂计价规则与收费组套独立版本化治理

复杂计价能力和收费组套在价表项目架构中保留，但不得作为普通价格条目的内嵌表达式或自由结构。计价规则拥有稳定身份和不可变版本，规则版本冻结输入变量、参数、计算结构、Decimal精度、舍入层级、适用约束、测试向量、审批和双时态，只允许执行受限、类型安全、确定性的表达式，禁止数据库SQL、任意脚本或运行时下载代码。价格条目必须在固定单价和一个已发布计价规则版本之间二选一。收费组套拥有独立稳定身份和不可变版本，版本冻结组成项、目标版本、数量、必选或可选关系、选择组、替代组、嵌套、计价和分摊方式，发布前必须验证无环、深度、组件有效性、数量约束和金额守恒。收费组套只表达收费组合，临床医嘱组套和路径属于临床域并通过显式映射衔接。组套解析和金额分摊必须生成不可变证据，分配金额总和等于组套金额并记录尾差去向。服务内涵、计价单位或收费方式发生实质变化时仍须新建收费项目身份，不能通过替换规则版本掩盖语义变化。后续ADR-0061和ADR-0065已将计价规则与收费组套纳入邻接薄切，并量化为4项计价规则且每项至少4个测试向量、4个收费组套及至少16个组成项。
