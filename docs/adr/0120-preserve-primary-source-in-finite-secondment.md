# 有来源的有限借调保留原主归属，并冻结独立来源依据

PV-006-C-04 仅授权当前单医院、真实科室之间的 SECONDMENT：来源必须是同一任用下已分类的唯一主归属，新临时任职保持同人员、任用和用途，有限期间完整落在当时可见的来源声明、任用与双方科室的有效窗口内。借调不结束或切分来源；同任用及用途的科室安置集合最多容纳一条期间重叠的借调声明。这些是本票保守合成工程规则，不是医院已批准的人事制度或临床许可。

临时任职沿用既有任职身份与完整版本轴，另有一份不可变、精确版本配对的来源依据；首次准入、来源关联、请求结果和审计原子形成。普通修改与语义纠正不能改造临时子任职，提前结束只追加非扩张关闭；到期由查询推导，无自动返回、恢复或重建来源。来源后续结束、调动或纠正仍可正常进行，子事实不追随变化，显式只读复核分别表达引用是否改变与依赖是否满足，保留原接受认知。
