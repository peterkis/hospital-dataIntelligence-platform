# 收费项目身份与价格条目分离

ADR-0058扩展本模型：价格条目除固定单价外可以引用一个独立已发布的计价规则版本，但不得内嵌任意表达式；收费组套也作为独立治理对象，不改变收费项目身份、版本和价格条目相互分离的原则。

院内收费项目拥有永久不复用的稳定身份，项目名称、服务内涵、包含或除外内容、计价单位和约束通过不可变项目版本表达，价格金额不属于项目身份。价表表达一套价格的适用上下文，价表发布版本形成不可变完整快照，价格条目将收费项目绑定到金额、币种、价格性质、业务有效期和适用范围。单纯调价只形成新的价格条目或价表版本；不改变收费边界的说明调整形成项目新版本；服务内涵、计价单位、包含或除外内容、计费方式发生实质变化时新建收费项目身份并记录替代或派生关系。外部或历史系统项目代码只作为有命名空间、有版本的映射，不代替院内稳定ID，已发布历史不得覆盖或物理删除。

外部代码在本项目中的含义由ADR-0053澄清：它们仅是系统间互操作映射，不是政策来源或定价依据。
