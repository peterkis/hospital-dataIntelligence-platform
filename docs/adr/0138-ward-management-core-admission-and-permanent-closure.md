# 病区管理准入、身份与永久关闭

用户批准P3-02由care-organization唯一维护病区。病区是收治或床位管理组织，
与科室、业务单元、护理单元、地点分别治理；名称相同不合并身份。代码全院
唯一且终身保留归属，改码和关闭不释放。属性与主管理关系独立版本化，
同院区显式更换管理业务单元保留病区ID；跨院区迁移由P3-11另行治理。

CORE发布必须具有同院区、完整期间覆盖及当前上游准入满足的真实已发布业务
单元。负责人和能力未就绪分别表达，不推导临床启用。病区类型保留独立核验
的版本化文本，收治限制绑定准确规则版本、材料及期间；无限制也须明确确认。

本票关闭是永久终态，持续遮蔽未来安排，保留身份、代码和全部原认知历史。
关闭不重走失效上游的扩张准入，但仍需当前权限、期待版本及独立审批。
可恢复暂停和完整下游交接另属P3-11，关闭本身不表示床位或护理处置完成。
这些决定允许独立CORE治理，代价是不得把主数据发布解释为可收治患者。
