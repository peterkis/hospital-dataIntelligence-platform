# Phase 01采用模块化单体治理应用和独立仿真消费者

Phase 01将管理界面所调用的治理后端建设为一个模块化单体部署单元，收费项目、价表、工作流、权限、版本、审计、快照和Outbox按明确模块边界组织并通过内部公开接口协作，但不拆成分布式微服务；仿真消费者位于治理应用边界之外，使用独立服务身份、消费状态和正式快照及变化契约，不能调用内部模块或直接访问治理数据库。该选择使发布、完整快照字节及元数据、审计和Outbox能够保持本地事务原子性，并把Phase 01资源集中用于验证领域不变量；未来只有出现真实团队边界、独立扩缩容或故障隔离需求时才评估沿模块契约拆分，任何改变事务或消费边界的拆分都必须重新执行架构门禁。Phase 01快照字节具体采用PostgreSQL `bytea`同事务存储，见[ADR-0093](0093-store-canonical-snapshot-bytes-in-postgresql-transactionally.md)。
