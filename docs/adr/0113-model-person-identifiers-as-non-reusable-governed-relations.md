# 人员标识作为不可复用的受治理关系

personId 始终是全院永久人员稳定身份。人员标识由明确命名空间与该命名空间下
已经规范化的值组成，只引用既有人员；平台不进行全局大小写、标点或 Unicode
归一化。同一治理对象内同一命名空间和值全历史只允许绑定一个人员，精确冲突
必须阻断并审计，不创建、合并或重新分配人员。业务有效期和断言撤回通过不可变
双时态版本表达，撤回不解除该唯一性约束。这牺牲了自动纠错和号码复用的便利，
以保留身份依据并避免静默转移历史。

来源系统记录键映射是独立关系，不属于人员标识命名空间。标识值、值摘要及原始
命令不进入审计、日志、错误或指标；审计仅保存关系引用和有界结果。本次实现仅
用于 SYNTHETIC / NON_PRODUCTION，不建立真实敏感标识的生产级存储保护。
