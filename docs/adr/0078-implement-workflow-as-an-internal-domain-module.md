# 工作流作为模块化单体内的领域模块

Phase 01在模块化单体内部建立独立工作流领域模块，以显式状态转换和PostgreSQL持久化执行审批，不引入外部流程引擎、BPMN、任意脚本或通用低代码流程设计器。审批模板具有稳定身份和不可变版本，只能组合平台预先定义的单级Owner审批、专业复核、端点前置确认及Owner终审阶段；变更请求提交时冻结模板版本、风险结果、必需阶段和内容摘要，模板新版不得自动迁移进行中的请求，超时只能提醒或升级待办而不能自动批准。每次流程动作与其只追加动作记录及审计在本地事务中提交；最终批准触发的发布继续服从既定发布、快照、审计和Outbox原子边界，未来只有出现跨应用长流程、动态流程设计、复杂定时补偿或独立工作流运维需求时才重新评估外部引擎。
