# 单元能力固定范围与参数显式重新采纳

用户批准 P3-08 能力关系固定 Unit、Campus、运营主体、服务集合、能力类型和
就诊场景。跨院区重新绑定保持 Unit 身份，但不传播旧能力；新范围独立授予新
能力身份。这样增加重新签审的成本，同时防止组织移动扩大临床行动范围。

未启用关系可激活，暂停关系可恢复；永久 END 不能恢复。暂停与未启用不会
释放仍在声明期间内的范围，避免通过另建关系绕过暂停。普通修订不能启停、
改范围或取消 END。安全收缩仍要求当前授权、期待版本、证据和独立批准。

governance-catalog 独立维护参数实际值，复用已有定义和签审机制。能力保留
准确已批准定义和值版本；当前适用批准版本变化时拒绝新准入，显式修订、核验
与批准才能重新采纳。此选择避免静默传播配置变化；草稿和历史记录不被覆盖。
仅 BOOLEAN_GATE_V1 具有本票执行语义。空规则也需独立无附加规则确认。

能力完整期间和当前许可分别评价，原接受证据与后来复核分开。组织能力不是
个人专项授权，也不证明真实诊疗科目许可或患者业务就绪。有限上游影响只读
识别，并以准确已提交 Owner 结果处置，不自动迁移其他领域事实。

本决定仅为 TEST POLICY ONLY 合成 CORE 开发；院方正式政策、P5 临床资格、
真实医嘱、FULL 和正式验收仍需独立完成。
