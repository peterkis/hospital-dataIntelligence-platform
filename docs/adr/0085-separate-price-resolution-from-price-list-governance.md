# 价格解析与价表治理分离为两个深模块

Phase 01在同一模块化单体、同一应用进程和同一PostgreSQL事务数据库内建立独立的`price-resolution`深模块，不因此拆分微服务。`price-list`继续独占价表稳定身份、草稿、不可变完整发布版本、价格条目及生命周期；它按价表身份、服务发生时间和记录时点确定唯一权威的已发布版本，并只通过小型接口提供不可变的已发布价格解析视图。该视图冻结价表发布版本及摘要、适用状态和时间、相关价格条目及摘要、目标版本引用以及计价规则版本引用，既不暴露草稿、数据库行或持久化类型，也不决定院区回退、通用/专用命中或最终金额。

`price-resolution`独占输入规范化、院区到全院固定两级解析、通用与专用模式判定、冲突失败关闭、固定价或已发布规则执行、Decimal计算与舍入，以及不可变解析证据；`price_resolution`、`price_resolution_step`和`price_resolution_result`由该模块拥有。它不得直接读取`price-list`表、访问草稿、修改价表或把解析结果回写为价格主数据；`price-list`及路由层也不得复制解析算法。解析证据必须冻结请求、已发布视图、候选条目、引用规则、顺序步骤和结果摘要，使价表后来新增或发布新版本后仍能按原输入重放历史结论。
