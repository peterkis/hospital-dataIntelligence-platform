# 价表POC使用五个合成外部代码命名空间

现阶段固定使用五个明确标记为合成的外部代码命名空间：`SIM_HIS_CHARGE`验证院内收费代码的导入、导出和双向确定绑定；`SIM_FINANCE_REVENUE`验证收费项目向财务收入科目的单向分类输出；`SIM_PHYSICAL_EXAM_ITEM`验证体检项目、收费项目和收费组套之间的映射；`SIM_LEGACY_CHARGE`验证历史代码版本、改名、停用、替代和历史解释；`SIM_CAMPUS_LOCAL_CHARGE`验证院区范围代码、全院项目映射和跨院区越权阻断。各命名空间分别配置系统与对象类型、代码格式、规范化及大小写规则、组织范围、用途、方向、Owner和代码复用策略。医保目录继续使用独立医保映射，政策资料使用政策适用认定，临床医嘱和执行服务使用三目录及医嘱收费规则，均不得混入这五类外部收费代码命名空间。所有样本均为合成数据，不冒充真实医院系统。
