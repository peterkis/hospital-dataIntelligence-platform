# 业务权限默认授予到治理对象

数据域只用于分类和责任聚合，不作为最低权限边界。数据管家、数据Owner等业务角色默认按具体治理对象授权，例如单部字典、代码系统、值域或一类主数据；数据域归属不得自动扩展为域内全部对象权限。每个治理对象分别授予查询、维护、审批、发布和审计权限，一个人可以组合多项权限，普通领域内容变更的提交人与审批人必须分离。该选择增加了授权配置数量，但避免数据域内对象过多时产生越权维护或审批。[ADR-0091](0091-govern-projection-schema-upgrades-as-high-risk-contract-changes.md)修订“始终分离”为限定规则：纯投影Schema契约升级允许提交人兼任平台契约终审人，但不减少领域语义确认、对象级授权或审计动作；一旦同时改变领域内容，仍恢复本决策的职责分离要求。
