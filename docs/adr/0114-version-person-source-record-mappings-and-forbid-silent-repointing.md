# 人员来源记录映射采用不可变版本并禁止无痕重指向

人员来源记录身份由治理对象、来源系统、来源业务实体和来源记录键共同确定，
并永久对应一个稳定映射ID；Person 指向只属于不可变映射版本。映射错误可以
纠正，但只能通过具有预期当前版本、直接前驱、受限原因和同事务审计的显式纠错
命令追加新版本，旧版本不得更新、删除或被重新注册绕过。这样牺牲了通用 upsert
和静默覆盖的便利，使记录时点查询能够同时重现过去判断与当前判断。

来源记录键不是人员标识，平台不据此创建或合并人员，也不回退到 Identifier
Registry 或模糊匹配。真实来源若会复用记录键，适配器必须提供能够区分 lineage
的更强不可变键；普通纠错不能掩盖真正的新来源记录。原始来源记录键及其摘要
不得进入审计、日志、错误或指标。本次实现仅用于 SYNTHETIC / NON_PRODUCTION，
不宣称具备真实人员来源键的生产级静态存储保护。
