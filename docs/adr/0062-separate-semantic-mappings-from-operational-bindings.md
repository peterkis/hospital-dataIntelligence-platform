# 外部代码语义映射与运行操作绑定分离

外部系统代码首先归属于受治理的命名空间，命名空间明确系统、对象类型、医院或院区范围、代码格式、规范化和大小写规则、代码复用策略、Owner及生命周期。外部代码拥有稳定身份和不可变语义版本，名称、说明或含义变化形成新版本，不覆盖历史。外部代码版本与院内收费项目版本之间的语义映射允许多对多，关系类型限定为等同、院内项目更窄、院内项目更宽或仅相关，并记录依据、范围、有效期、审批和审计；语义映射不保证运行转换唯一。导入、导出、查询、历史解释或仿真消费等运行用途通过独立操作绑定处理，在同一外部代码版本、用途、方向、院区范围和业务时点必须唯一绑定到一个院内收费项目版本、收费组套版本或已发布映射规则。需要一对多生成收费明细时必须绑定规则或组套，不能从多条普通语义映射中随机选择。任一侧语义变化、停用或替代均触发显式重审；名称相似只能产生待确认建议，不能自动发布。映射不得承载价格、政策适用、医保待遇或医嘱收费规则内容。
