# 组织生命周期与准确原子搬迁交接

用户在2026-10-08批准P3-11完整计划。业务单元、病区、护理单元在原永久身份和版本流上追加暂停、显式恢复和永久退出。暂停不释放既有责任或地点占位；恢复重新核验完整期间，不恢复已永久结束的关系。旧暂停和永久退出事实及原认知保留，属性修订和未来安排不能改变生命周期。

同院区换地点只结束旧地点使用并建立新使用。跨院区组织重新绑定保留组织及逻辑科室身份，原院区能力、许可和关系逐项显式处置，目标范围重新核验。病区的院区归属按准确绑定版本解释；物理地点身份仍不得跨院区迁移。楼宇调整不改变行政树或人员主归属。

护理部分交接永久结束原完整覆盖，建立保留及接收范围的新关系。分区集保留身份并追加不可变完整版本，新分区ID由数据库生成；准确旧新映射、物理边界材料及责任连续性需独立核验。新分区不隐式释放旧责任。此决定扩展ADR0137、0138、0142原先交给P3-11的范围，已接受旧事实与回执不改写。
