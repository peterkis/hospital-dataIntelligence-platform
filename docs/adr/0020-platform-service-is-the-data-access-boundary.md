# 平台服务是基础数据访问边界

ADR-0059扩展了平台对下游消费者的供数契约：长期架构保留发布快照、变更通知、游标、水位、回执和重放，现阶段仅以同契约仿真消费者验证，仍不得绕过平台服务直接访问数据库。

管理界面与REST API共用同一套权限、校验、版本、流程和审计服务，业务用户、治理角色及仿真消费者不得绕过平台服务直接访问数据库；API写入只能形成草稿或导入批次，不能绕过审批直接发布。数据库管理员仅可因运维、备份恢复或故障处置，通过受控且全程审计的通道访问，不得代替业务角色维护或发布基础数据。应用服务使用最小权限的独立服务账号访问数据库。该边界牺牲直接数据库操作的便利性，以保证所有业务行为都经过一致治理。
