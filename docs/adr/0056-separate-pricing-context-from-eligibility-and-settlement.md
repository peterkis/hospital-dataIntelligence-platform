# 定价维度与资格、映射及结算维度分离

普通院内价格只依据可定价对象、明确价表、组织范围、门诊、住院、急诊、体检四类实际就诊场景、通用或专用价格模式以及服务发生时间解析；ADR-0067进一步要求同一范围和时段内通用与专用模式严格互斥。科室、执行单元和人员角色是否可以开展、执行或收费，由独立版本化的收费资格或医嘱收费映射规则决定；规则可以允许、阻断或要求复核，但不得生成不同价格。医保及其他支付身份进入独立待遇治理，不参与院内价格选择。未来确有体检合同价或商业协议价时，应以具有独立合同身份、版本、适用对象和有效期的协议价表表达，不在普通价格条目中增加通用`payer_class`、患者类别或自由条件表达式。资格、映射、待遇和合同结算均可消费价格解析结果并分别留证，但不得反向覆盖院内标准价或暗中选择另一价格。
