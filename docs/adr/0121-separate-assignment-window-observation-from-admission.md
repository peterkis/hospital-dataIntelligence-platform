# 分开任职窗口观察、原接受证据与后续写入准入

PV-006-C-05 增加单一完整业务区间的只读消费边界：先选记录认知下最新完整任职版本，再判断整个窗口覆盖；未完全覆盖时明确返回差集，不以旧开放版本或裁剪窗口补足。冻结用途、方式及原准入/关闭/来源依据保留，结构依赖按显式窗口重新观察，旧 exact/full-assessment 的问题和结果口径保持不变。

不同 owner 的事实必须共享一次局部一致快照，敏感读审计在快照结束后独立追加并传播失败。观察不锁住未来，指纹不构成授权；后续角色或其他 mutation 仍须自己的当前权限、版本、依赖围栏与领域规则。本票只决定合成工程消费边界，不扩大医院人事政策、Mode、角色、临床权限或发布范围。
