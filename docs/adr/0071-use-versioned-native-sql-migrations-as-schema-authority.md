# 以版本化原生SQL迁移作为数据库结构唯一权威

Phase 01的PostgreSQL物理结构及其演进只由有序、版本化的原生SQL迁移定义；ORM、查询框架和应用启动过程可以查询、映射或校验既有结构，但不得自动创建、修改或删除数据库对象。尚未进入正式架构证据包的迁移可以在开发期修订，一旦被纳入有证据的基线，其文件与摘要即不可修改，后续纠正只能追加新迁移。唯一性、引用完整性、二选一和时间不重叠等核心不变量必须落实为PostgreSQL声明式约束，只追加边界还必须由数据库角色、权限及必要的受控数据库机制共同保证，不能仅依赖界面、应用约定或ORM钩子。迁移执行工具、查询库和类型生成工具可以后续选择或替换，但不得取得Schema主权；若要改变上述规则，必须先形成新的或取代性ADR并重新确认核心架构。
