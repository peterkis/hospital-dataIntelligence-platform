# 价表POC分为核心完整实现、邻接薄切和长期预留

现阶段价表POC采用三层范围。核心完整实现层包括收费项目及版本、价表及发布版本、价格条目、外部系统代码映射、价格解析证据，以及导入、审批、发布、审计、Outbox和同契约仿真消费闭环，必须覆盖新增、查询、版本化修改、草稿删除、发布后失效、导入幂等、双时态、影响分析和补偿发布。邻接薄切验证层包括政策来源资料及适用认定、医保目录项目及收费项目映射、代表性待遇规则、收费资格规则、计价规则、收费组套、医嘱目录、执行服务目录和医嘱收费映射；每类只建立少量代表样本，但样本仍须完成CRUD生命周期、不可变版本、对象级授权、职责分离审批、发布失效、审计、影响事项和适用的解析留证，不能退化为静态桩。长期预留层包括真实患者资格、医嘱、执行、账单和结算事实，完整医保待遇引擎、全量临床目录、真实系统接入、生产消息设施、缓存、SLA、灾备、影子计费、真实对账和当前无明确合同需求的协议价表，只保留架构与契约边界，不进入现阶段实现或验收承诺。
