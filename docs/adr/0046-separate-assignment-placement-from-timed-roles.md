# 任职安置与有期限的任职角色分离

每条任职隶属于且仅隶属于一条任用关系，并以独立任职ID、业务有效期、双时态和不可变版本表达人员在医院级、院区级或科室级作用域中的组织安置。任职用途与任职方式正交治理，主归属唯一性按人员、任用关系、用途、作用域和业务时间校验，不实行人员全院唯一当前科室。岗位和职责通过独立、有期限的任职角色表达；科室主任等负责人不进入科室版本，其持有人数约束按角色、科室和业务时间配置。调动结束旧任职并建立新任职，兼职、借调和轮转分别建立并行或有期限关系且保留来源任职；科室变化只产生影响事项，不自动迁移人员。发布时冻结所引用的组织、字典和约束规则版本，后续变化不改写历史。
