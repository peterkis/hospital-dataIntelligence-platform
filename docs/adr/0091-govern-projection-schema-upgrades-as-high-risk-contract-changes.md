# 投影Schema升级按高风险契约变更治理

投影Schema升级一律作为高风险契约变更治理。所属领域Owner确认字段语义、约束和领域投影含义没有被误改，平台契约Owner确认TypeBox及冻结OpenAPI外部结构、契约身份和证据完整性；平台契约Owner不取得领域内容或投影Schema编辑主权，领域模块仍是Schema定义及语义的唯一所有者。

终审前必须冻结TypeBox及OpenAPI差异、基于活动订阅精确支持声明形成的兼容矩阵、使用冻结契约生成客户端执行的仿真消费者测试，以及对象、消费者、历史快照和迁移准备的影响分析。消费者Owner只能发布支持版本和迁移准备声明，不能批准、否决或拖延领域契约发布；不兼容继续按ADR-0089仅阻断对应投递。兼容矩阵和测试不得通过发布时网络探测消费者、字段试读或运行时协商生成。

本决策对既有提交—审批职责分离建立一个窄范围例外：仅当变更被证明为不改变领域内容版本或成员集合的纯投影Schema契约升级时，提交人可以兼任平台契约终审人；领域语义确认和平台契约确认仍是两个显式、分别授权且分别审计的责任动作，同一人只有同时持有相应对象级权限时才能执行。若同一请求同时改变任何领域内容、业务规则、成员集合或生命周期，例外立即失效，必须继续遵守普通领域治理流程的提交人与最终审批人分离。该例外不得扩展到人员、科室、价表内容、映射、值域、数据元或其他普通治理变更。领域内容等价证据与投影载荷、完整快照制品摘要的分层由[ADR-0092](0092-use-separate-projection-payload-and-snapshot-artifact-digests.md)进一步限定。
