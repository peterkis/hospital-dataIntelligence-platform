# 冻结受控导出容量专用负载画像矩阵

完整POC派生交付制品容量实验使用容量专用、确定性且相互可比较的合成负载画像矩阵。画像中的“行数”统一指最终`records.csv`的数据行数，不含表头；它不是收费项目稳定身份数量、价表版本数量、数据库行数、规范快照成员数或生产数据规模承诺。

矩阵冻结为以下七个画像：

| 画像 | 最终导出数据行数 | 目的与边界 |
|---|---:|---|
| `F00` | 24 | 容量链路功能对照，只证明小样本路径和确定性，不参与容量上限推导 |
| `N10` | 10,000 | 普通字段分布的低规模测量点 |
| `N30` | 30,000 | 普通字段分布的中间测量点 |
| `N50` | 50,000 | 普通字段分布的主要参考点，代表“价表初始化通常为数万条”的合成设计输入，不冒称真实医院统计 |
| `N100` | 100,000 | 普通字段分布的高记录数压力点，只用于观察架构余量，不形成生产容量承诺 |
| `W50` | 50,000 | 全部可选输出字段有值，变长字段接近冻结契约允许上限，用于隔离行宽压力 |
| `E50` | 50,000 | 保持普通行宽规则，确定性覆盖中文、多字节字符及冻结Schema允许的CSV逗号、双引号和换行转义，用于隔离编码与转义压力 |

`N10`、`N30`、`N50`和`N100`必须使用同一普通字段生成规则，只改变最终数据行数，以形成可比较的规模曲线。`W50`与`E50`分别隔离行宽和编码/转义压力，不得把两者混成一个无法解释压力来源的画像。[ADR-0109](0109-freeze-managed-export-capacity-field-distribution-rules.md)进一步冻结普通画像70/25/5的短中长分布及20%/50%/85%目标长度、`W50`的90%目标长度，以及`E50`五类各20%的字符与转义分布和显式字段资格规则。

所有画像均使用独立于业务功能验收数据的容量专用合成身份空间、来源投影和消费者交付配置。画像记录必须符合冻结Schema，业务键唯一、引用完整、排序稳定且可以成功完成确定性转换；不得混入重复、缺失映射、非法值或其他错误记录，把校验失败、错误留证或重试成本伪装成制品容量。`F00`也不得直接复用24个收费项目及3个价表快照的业务验收fixture。

每个画像必须冻结稳定画像身份、精确来源投影Schema身份、消费者交付配置及格式版本、生成器和代码版本摘要、随机种子、最终行数、字段分布规则、记录全序及适用的字符/转义集合。前置可行性实验和集成后真实链路核验必须引用同一画像版本并逐字节核验生成结果；画像修改只能形成新版本和新证据运行，不得覆盖既有画像或结果。

所有会进入派生制品的变长字符串字段必须在冻结外部契约中具有可执行的有限最大长度；任一字段缺少最大长度、画像生成超出Schema合法范围或不能确定适用的字符集合时，该画像不得冻结，容量实验失败关闭。该规则不要求现在锁定物理DDL，但防止以无界字符串得到不可解释的容量结论。

本画像矩阵只服务于合成完整POC的两阶段容量证据，不扩大24个收费项目、3个价表快照、A01至G12共72个REST场景、U01至U20共20个界面场景或Phase 01 ABG-01至ABG-40。10,000至100,000只是测量点，不是容量上限、全院初始化规模、生产SLA、部署规格或招标参数；字段分布已由ADR-0109冻结，受限本机WSL2容量环境由[ADR-0110](0110-use-local-wsl2-anolis-8-9-for-capacity-simulation.md)冻结，重复次数、峰值RSS/磁盘余量/时间阈值、结果聚合判定和最终容量数值继续逐项确认。
