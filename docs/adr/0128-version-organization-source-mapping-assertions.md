# 组织源映射采用完整不可变断言版本

P2-03会话批准：来源系统、源实体类型、源代码和精确上下文确定永久映射身份；目标指向属于不可变版本。REGISTER不能upsert；CORRECT要求expectedHead、直接前驱、理由和独立审批，追加完整替代断言。给定记录时点先选最新版本，再检查业务期间，不从已结束或已撤回版本回退旧开放版。RETRACT撤回整条断言；旧R仍复现过去认知。

上下文不是通配符，也不构成院区授权。源键真实复用通过另行批准的新上下文区分，不能用普通纠错掩盖。SRC-COND-023以精确上下文与期间的可执行唯一性检查，加独立信息管理部核验编译；不执行自由文本规则。CORE保留19字段，只有已实现Owner及EXACT可应用，其他关系及FULL保持明确阻断。

一revision是一个最多100条命令的批准原子单元，不能沿用ORG04独立行处理。目标只通过事务内公开Owner引用port读取；命名空间、上下文、院区、目标引用分别取得当前权限。新建/换目标/扩张重新准入；纯期间收缩和撤回保留当前授权与独立审批，允许失效上游退出。
