# 冻结病区护理范围与已确认连续交接

P3-05 采用病区专属、独立批准的完整互斥逻辑分区集；只允许全病区或准确版本的非空分区集合。机器检查结构与引用，物理边界真实性由独立核验负责。批准后固定划分，边界重划及部分交接留 P3-11，避免在缺乏床位领域事实时隐式推导责任。

护理覆盖以固定 Ward、NursingUnit、Campus、NURSING_COVERAGE 用途和起点追加完整声明；最新有限声明不回退旧开放声明，END 永久缩短或取消。相交范围至多一个主要责任，不同护理单元的协作需一致的准确规则、完整参与者、范围和期间；暂停不自动释放责任。独立确认后，在同一事务和记录时点结束旧覆盖、建立相同范围的新覆盖，保留原事实及证据。未来交接明确待生效，安全结束可留下可查询缺口。

范围登记、核验、审批、原子发布和恢复复用 Catalog 管道及账本，关系 Owner 独立守护 SQL 写入。窗口查询分开声明责任、主要责任、当前准入和原接受依据。该选择增加签审及联合修订成本，换取责任连续性和可追溯性。
