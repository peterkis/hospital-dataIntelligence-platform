# 全院身份集中主权并由专业领域分别治理事实

人员稳定身份、核心身份属性和身份消歧由全院人员主数据Owner集中治理；任用、任职、专业资质、层级视图、代码系统和值域由人力资源、组织、医务、护理、教学等明确的领域Owner分别负责，院区和科室数据管家只能在获授权对象及院区范围内维护并提交。一个组织与人员权威来源负责人员身份和权威初值，多专业Owner不构成多个竞争的人员黄金源。跨院区兼职、借调、轮转或主归属调动需要来源院区与目标院区完成必要前置确认，再由该对象唯一的全院领域Owner最终审批；院区确认不形成并列所有权。任一必需确认拒绝或缺失时当前对象不得发布，其他独立对象不回滚。提交人与最终审批人必须不同，审批后仅由平台服务执行发布，所有确认和审批按操作者、角色、院区、理由、时间及所见版本完整审计。
