# 院区可扩展但不得覆盖全院条目

本决策继续适用于基础数据条目的身份和内容。ADR-0057进一步澄清：全院价格Owner可以在同一价表中发布显式院区差异价；这不是院区自行覆盖全院条目，也不赋予院区管理员发布权限。

治理对象可配置是否允许院区扩展。允许时，院区可以新增仅本院区使用的条目，但不得复用全院条目的稳定标识或业务唯一键，也不得直接修改、停用或覆盖全院条目；本地名称、旧编码或本地语义差异通过显式院区映射表达。纯院区条目由院区Owner审批，涉及全院标准映射时由全院级Owner复核；院区条目升格为全院标准时在全院级治理对象中另行发起变更。该选择保留院区差异，同时避免同一标识在不同范围出现隐式优先级。
