# ADR-0133: STATISTICAL 冻结来源快照

状态：Accepted（2026-10-02，P2-06 用户明确确认）

## 背景

ADR-0032 将 STATISTICAL 注册为保留类型而禁止发布。P2-06 AC-03 需要通过公共 Owner 发布真实冻结来源，再证明科室更名不会改写它。

## 决策

仅当 `viewType=STATISTICAL` 且 `aggregationRule=FROZEN_SOURCE` 时允许沿既有层级候选、独立审签、发布和查询流程保存来源快照。其名称、树、精确科室版本、来源证据和摘要随发布版本冻结；当前影响评估另外保存，不重述源快照。

此决定仅替代 ADR-0032 对这一组合的发布禁令。其他 STATISTICAL 口径及全部 FINANCE 发布仍禁止。没有统计计算、汇总指标、重算任务、财务视图或正式统计验收能力。

## 验证

P2-06 数据库专项通过公共 Owner 发布该组合，在负责人科室更名后逐字段比较原发布快照。既有拒绝未支持统计口径和 FINANCE 的验证继续适用。前向迁移 0124 同时限制候选存储和发布 SQL 门禁。
