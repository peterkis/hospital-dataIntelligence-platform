# 价格解析采用全院默认、院区只扩展和服务发生时间

本决策关于服务发生时间、场景维度、双时态、唯一命中和失败关闭的内容继续有效。ADR-0057取代“同一全院收费项目绝不允许院区差异价”的部分，改为由全院价格Owner显式批准院区差异价并使用固定两级解析；仍禁止数字优先级和院区自行覆盖。

ADR-0074进一步将`Asia/Shanghai`从价表时间规则提升为全系统固定时区，并规定所有日期时间均采用无时区本地日期时间表达。

ADR-0067进一步澄清门诊、住院、急诊和体检是四类实际场景，“通用”是覆盖四类场景的通配价格模式，并与专用场景模式严格互斥。

价表POC仅按全院默认或经全院价格Owner批准的院区差异两类组织范围、四类实际就诊场景及通用通配模式确定适用价格，不按科室、人员、患者类别、医保身份或支付方式定价。全院价表是默认价格来源；院区可以增加本院区扩展项目或映射，也可以申请差异价，但不能自行批准或发布对全院默认价的覆盖。同一可定价对象、价表、组织范围、场景模式和业务时段必须唯一且无通用与专用重叠；多重命中必须失败关闭，不能按数字优先级或最具体规则自动择优。价格以服务实际发生时间为计价基准，有效区间采用`[valid_from, valid_to)`并按`Asia/Shanghai`解释，同时保留业务有效时间和平台记录时间。追溯更正形成新价表发布版本和影响事项，不覆盖历史或自动修改患者费用。
