# 全院默认价格允许Owner批准的院区差异价

全院价格继续作为默认价格来源。确有业务依据时，全院价格Owner可以为同一收费项目和指定院区显式批准并发布院区差异价；院区数据管家只能提出申请或维护草稿，不能自行审批、发布或覆盖全院默认价。价格解析采用固定两级算法：先查找唯一有效的显式院区差异价，不存在时回退到唯一有效的全院默认价；每一层多重命中均失败关闭并产生价格冲突事项，不设置数字优先级，也不采用条件特异性、更新时间或最后写入者择优。若院区差异实际改变服务内涵、计价单位、包含或除外范围，应建立院区扩展收费项目而不是差异价。解析证据必须保存命中院区价或回退全院价的完整路径。本决策修订ADR-0052的院区价格范围，并澄清ADR-0023仍禁止院区自行覆盖全院基础数据。
