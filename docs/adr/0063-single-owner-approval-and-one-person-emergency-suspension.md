# 价表采用单一Owner终审和紧急单人暂停

价表项目中的每个治理对象在同一业务时点只有一个最终内容Owner。跨域映射、规则或范围变更需要所有受影响端点Owner完成前置确认，再由唯一对象Owner终审；前置确认不形成联合所有权，也不导致跨对象原子发布。收费项目实质语义变化、价表发布、追溯更正、院区差异价、计价规则和收费组套采用专业复核与对象Owner批准的两级流程，普通证据登记和低风险映射可按对象审批模板使用单级Owner审批。普通领域内容变更的提交人与最终审批人不得相同，审批完成后由平台服务自动发布，不设置可绕过审批的人工发布员。[ADR-0091](0091-govern-projection-schema-upgrades-as-high-risk-contract-changes.md)仅允许不改变领域内容的纯投影Schema契约升级由提交人兼任平台契约终审人；任何价表内容、规则、成员或生命周期变化仍完全服从本决策。

紧急暂停是明确例外：获得指定治理对象和范围`EMERGENCY_SUSPEND`独立权限的一名授权人员，可以立即暂停已发布对象供未来新解析使用，无需第二人事前确认。紧急动作只能追加暂停事件、阻断未来新解析并生成影响事项，不得修改、删除、覆盖已发布内容，亦不得改写历史解析或费用结果。平台必须自动建立高优先级事后复核和影响闭环，记录原因、依据、对象版本、生效时间、操作者、授权范围、受影响消费者及通知回执。恢复只能通过新修正版、补偿发布或重新发布经验证历史内容，并完成正常审批；不得原地取消暂停，紧急操作者也不得审批自己提交的恢复变更。
