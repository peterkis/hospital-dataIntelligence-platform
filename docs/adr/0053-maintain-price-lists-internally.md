# 价表由医院内部维护且外部代码仅用于映射

本决策保留为历史记录，但其“完全不建设政策源文件证据”的部分已由[ADR-0054](0054-separate-policy-evidence-from-internal-price-sovereignty.md)取代。院内价格主权和外部系统代码只用于映射的部分继续有效。

院内收费项目语义、价表和价格金额均由医院在平台内维护、审批和发布，不从国家、地方或医保价格政策目录采纳生成，也不建设政策源文件证据和外部政策快照。HIS、财务、体检或历史系统等项目代码只作为独立版本化的互操作映射，不直接充当院内收费项目稳定ID、价格来源或定价依据；外部代码变化只触发映射重审，不自动迁移院内项目或价格。本阶段映射仅使用合成命名空间和仿真消费者。
