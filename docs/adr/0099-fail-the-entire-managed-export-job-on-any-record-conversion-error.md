# 任一记录确定性转换失败使整个受控导出作业失败

`MANAGED_EXPORT_HANDOFF`执行固定规范快照和冻结消费者交付配置时，只要任一来源记录因值、类型、必需映射或声明约束而无法完成确定性转换，整个初始化导出作业即进入终态转换失败。失败作业不得形成完成的`managed_export_artifact`、可下载或可交接制品，也不得产生成功交接、消费者应用回执、对账通过结论或检查点推进；生成过程中的临时或部分字节不取得派生交付制品身份。

平台必须为转换失败保留只追加的作业级和行级证据，使每个已发现错误可追溯到来源发布与快照、冻结配置版本、来源成员身份或作业内序号、失败字段或转换操作、稳定错误码和安全诊断摘要。不得只保存一个笼统“导出失败”标志，也不得通过删除错误、人工跳过、静默丢弃或交付“成功记录＋错误清单”把不完整成员集合冒充初始化基线。

转换失败的作业、错误和任何诊断证据不得覆盖或改换来源。修正来源内容、代码映射或消费者交付配置时，必须按各对象既有语义形成新的发布或版本，并创建新的初始化导出作业；新作业不能回写原失败作业。该规则只约束已发布快照的对外交付，不改变导入阶段“单行失败不回滚其他成功行”的既有语义。

本决策只处理固定输入下可重复出现的数据转换失败，不决定发现首个错误后是否继续扫描其余记录。[ADR-0102](0102-retry-transient-managed-export-failures-within-the-same-frozen-job.md)进一步把进程崩溃、临时存储、数据库或I/O故障等技术错误与本决策的转换失败分离：明确可重试的瞬时技术故障可以在同一冻结作业内有限重试，转换失败仍只能修正版本并新建作业。[ADR-0100](0100-stage-managed-export-after-phase-01-and-reserve-record-push.md)确认该语义不进入Phase 01，但必须在架构门禁通过后的完整POC受控导出邻接薄切中以合成仿真消费者验证；[ADR-0101](0101-expand-managed-export-acceptance-baseline-to-72-rest-and-20-ui-scenarios.md)把整作业失败、零制品、行级证据和新作业修正分别纳入G09、G10及U19。
