# 区分任职关闭与准入证据，并固定显式关闭后的关系期限

PV-006-C-03-01 在同一任职不可变完整期限轴上区分正向接受与非扩张关闭。
关闭保持直接前版开始边界，只能将终点确定为不晚于原有限终点的有限时点，
且不得产生空区间；首次显式确认原有限终点也属于关闭。记录时间由当前数据库
生成，可以声明未来结束或补录过去结束，不倒填认知时间。

关闭使用独立证据，精确引用直接前版的接受依据与已冻结用途、方式，不重新
声称剩余期间获得准入。任用、科室或定义后来失效不会阻断被当前有权人员
执行的非扩张关闭；身份、治理范围、独立结束权限、完整证据与并发版本检查
仍为硬约束。原正向写入的准入要求保持不变。

显式关闭后，本票禁止该稳定任职追加任何普通修改、语义采用、更正或再次结束。
关闭撤销和终点纠错需要独立能力；这一选择牺牲即时修正便利，以避免通过旧修改
入口重新开放关系。旧成功请求的当前授权后重放仍返回原版本，不产生新事实。

声明查询先选记录认知下最新完整任职版本，再按业务时点判断期间。关闭版本
继承直接前版分类；未分类仍未知。结束边界前的主归属保留，边界及以后才释放，
旧记录认知不受后来关闭影响。该声明不证明依赖有效、医院审批或临床资格。
本票仅为合成、非生产的工程规则，不实现调动、新目标关系或上游自动处置。
