# 任职原子调动共用一次操作知识时间

PV-006-C-03-02 仅允许已分类任职在同一人员、任用和用途/方式代码下更换真实科室身份。
来源原期间 [F,U) 在 F<T<U 处分成来源关闭 [F,T) 与新目标准入 [T,U)，不裁剪或延长。
来源引用原接受与冻结语义，目标按本次知识重新选择定义和完整依赖。失败回滚两端，不能自动改为单独结束。

根请求沿用任职命令账本；两个有界派生子请求必须与不可变调动映射一起提交。
数据库在必要串行化围栏后签发共同操作知识时间，供来源关闭、目标身份/V1/语义和依赖评价共同使用。
这不是提交时间。选择这一约束是为了既有历史声明与主归属入口不会因两端写入耗时产生人为认知空档；
普通结束与普通准入继续原有时钟语义，审计保留真实追加时钟。

这些是合成、非生产工程规则；不实现医院审批、角色资质、撤销、批量迁移或跨任用调动。
