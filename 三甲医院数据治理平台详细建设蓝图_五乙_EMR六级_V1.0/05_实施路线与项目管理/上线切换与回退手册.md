# 上线切换与回退手册（模板）

## 1. 适用范围
本手册用于数据标准、MDM、CDR、API、事件、质量规则、知识规则和证据中心的生产上线。任何影响患者身份、医嘱、结果、临床闭环或下游关键系统的变更，必须执行双人复核和回退演练。

## 2. 上线前七类门禁
1. **范围门禁**：变更单、需求、设计、模型、接口和测试用例使用同一版本号。
2. **数据门禁**：全量对账完成；P0质量规则100%通过；历史异常有处置清单。
3. **接口门禁**：消费者登记、契约测试、幂等、重试、死信和回执测试完成。
4. **安全门禁**：权限矩阵、字段脱敏、密钥、审计、导出控制和账号复核完成。
5. **性能门禁**：峰值、长稳、积压恢复和降级测试通过。
6. **临床安全门禁**：闭环状态机与CDSS规则经临床专家批准，影子运行和灰度方案完成。
7. **回退门禁**：数据库快照、旧版本镜像、配置、规则和消费者回退步骤演练通过。

## 3. 建议切换步骤
- T-30天：冻结范围；完成生产数据剖析和下游消费者清单。
- T-14天：完成全链路演练、容灾演练和业务UAT；发布用户通知。
- T-7天：执行增量追平；清理P0/P1问题；确认值守表和应急通讯录。
- T-1天：冻结非紧急标准、主数据和接口变更；备份配置库、元数据库和规则库。
- T0：停止相关写入或进入双写；完成最后增量；切换API/Topic/路由；执行冒烟测试。
- T+2小时：核对数据量、关键业务、消息积压、错误率、闭环节点和审计日志。
- T+24小时：业务部门签字；解除冻结；进入90天稳定观察。

## 4. 回退触发条件
- 患者误合并、核心主数据错误下发或临床事实错配。
- 关键系统调用错误率持续超过5%或P95时延连续15分钟超SLA两倍。
- 消息积压无法在约定窗口恢复，且影响闭环或临床工作。
- 权限越权、敏感信息泄露、审计缺失或密钥异常。
- 规则大规模误报/漏报，可能影响医疗安全。

## 5. 回退操作
1. 宣布回退并冻结新增变更；保全审计和现场证据。
2. 切回旧API网关路由、旧Topic版本或旧服务镜像。
3. 恢复规则/术语/主数据上一个可用版本；患者合并执行拆分和补偿事件。
4. 对下游执行回放或逆向补偿；不得仅回滚中央库而忽略消费者。
5. 对账、业务复核和安全检查通过后恢复服务。
6. 24小时内形成根因、影响面、修复和防复发报告。

## 6. 值守与证据
必须保存切换脚本哈希、操作者、审批、时间、版本、监控截图/导出、测试记录、异常处理、回退点、下游回执和业务签字。证据应进入证据中心而不是散落在即时通讯工具。
